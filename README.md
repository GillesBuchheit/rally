# Rally

Rally est une application composée d'une API Spring Boot et, à terme, d'une
PWA React.

## Backend

Le backend se trouve dans [`backend`](backend). Il utilise Spring Boot 4,
Java 25, Maven et Lombok.

```bash
cd backend
mvn spring-boot:run
```
